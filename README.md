## 🚀 Quick Start

```bash
# Check Python version
python --version

# Create and activate a virtual environment (Windows)
python -m venv venv
venv\Scripts\activate

# Run a Python script
python lab_script.py
```

## ✨ Requirements

- Python 3.8+
- pip
- virtualenv or venv
- Basic programming knowledge
